# Java

Typed Java actions — compilation through a warm `javac` worker, jar assembly,
JUnit test runs — with the **jvm-abi** lens (`abi`) so a dependent recompiles
only when an upstream module's public API changes, and resolver adapters
(`pom`, `maven`, `gradle`) that adopt an existing build's classpath.
