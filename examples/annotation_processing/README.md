# Annotation processing

This self-contained example builds a Java annotation processor, then compiles
an application with that jar on both `classpath` and `processorpath`:

```sh
python examples/annotation_processing/brix_build.py build app
java -jar examples/annotation_processing/build/app.jar
```

The output is `generated by brix`.

To exercise the important incremental case, change how
`MessageProcessor.java` writes `GeneratedMessage` without changing its public
types or method signatures, then rebuild. Brix recompiles the application
because processor jars are fingerprinted by their complete bytes. A normal
compile classpath uses the `jvm-abi` lens instead, where implementation-only
changes intentionally do not rebuild dependents.
