    C++¶

    Typed C/C++ actions — compile, archive, link — plus a pkg-config resolver. They lower to the generic action model, so they compose with any other language in one graph, and compilation automatically tracks #include headers through the compiler's depfile.

    Typed C++ actions.

    Strongly typed, ergonomic declarations — no magic string keys — that lower into the same generic action/data model as ExternalProcessAction when added to a graph. Raw and typed forms compose freely.

    graph.add(
    cpp.CompileSourceAction(
        source_files=data.glob("src/{name}.cpp"),
        object_files=data.glob("build/obj/{name}.o"),
        compiler=data.tool("c++"),
        compile_options=["-O2", "-std=c++20"],
    ),
    cpp.LinkApplicationAction(
        object_files=data.glob("build/obj/{name}.o"),
        output_file=data.file("build/bin/app"),
        linker=data.tool("c++"),
    ),
)

    CompileSourceAction ¶

    CompileSourceAction(
    *,
    source_files,
    object_files,
    compiler=None,
    compile_options=None,
    deps=None
)

    Bases: Action

    Compile every matching source into its object file, in parallel.

    Lowers to an ExpandAll over source_files whose child compiles one translation unit; source_files and object_files must share one binding name (e.g. src/{name}.cpp → build/obj/{name}.o).

    ArchiveAction ¶

    ArchiveAction(*, object_files, output_file, ar=None)

    Bases: Action

    Bundle object files into a static library with ar.

    Uses ar Dcrs: Deterministic (no timestamps/uids, so the archive is byte-reproducible — its content hash is stable when the objects are, which keeps dependents from re-linking spuriously), create, replace, and build the symbol index. Link against the result by passing it as one of LinkApplicationAction's object_files (the linker pulls the members it needs).

    Note on removed sources: ar updates an existing archive rather than rebuilding it. Under the atomic layer (the recommended stack) the archive is written into fresh staging each build, so a deleted source cannot leave a stale member. Without atomic, run clean after removing a source that fed the library.

    pkg_config ¶

    pkg_config(names, *, pkg_config='pkg-config')

    Resolve installed system libraries via pkg-config into a DepSet: --cflags become the set's compile flags (-I/-D) and --libs its link flags (-L/-l). Feed it to CompileSourceAction(deps=...) and LinkApplicationAction(deps=...).
